## בדיקה בפורטל המקומי

Chromium עם Playwright ב־1280×800 וב־390×844, בעברית ובאזור הזמן `Asia/Jerusalem`. כל ריצה השתמשה ב־SQLite זמני של `scripts/portal-smoke-server.js`. החשבונית וההזמנה ההיסטורית הן מזרע הבדיקות הקיים. אותה הרצה הפעילה את המחירון שכבר היה בזרע והציגה את נתוני תרחיש תעודת המשלוח של הבדיקות. ההזמנה עם שמונה משפחות נוצרה דרך הפורטל מתוך ברירות המחדל של עורך הצורות. סביבת הייצור והודעות אמיתיות לא שימשו לבדיקה.

### HAR-20 מול main

קריסת `savePortalDraft`, קריאת הקטלוג הפנימי עם 401, שגיאות אישור של ליפטים וכלונסאות, ואובדן שורות בעת רענון היו דיווחים תקפים בגרסה המתועדת בכרטיס. PR #18 כבר כלול בבסיס. בבדיקה הנוכחית נשמרו ושוחזרו שורות, הקטלוג נטען דרך `/api/c/shape-definitions`, וליפטים וכלונסאות נשמרו עם חוזי צורה תקינים. בדיקות הדפדפן הקיימות מכסות גם ניסיון חוזר לאחר שנשלחה הזמנה ותשובתה אבדה, אימות אימייל, שינוי PIN במסך ממוסך, קישור שפג תוקפו ורענון רשימת הבית אחרי אישור. חסימה של תאריך אספקה שעבר כבר הייתה קיימת בבסיס. לא שינינו את הכלל. [HAR-20](https://linear.app/hareimidbar/issue/HAR-20/tene-customer-portal-fix-save-draft-crash-catalog-401-shape-types) · [PR #18](https://github.com/meircodex/tene-industry/pull/18)

## אימות חוזר

```sh
npm test
PORTAL_CHROMIUM=/usr/bin/chromium npm run test:portal-quality
PORTAL_SMOKE_QUALITY_FIXTURES=1 node scripts/portal-smoke-server.js 3199
```

יש לפתוח את כתובת הפורטל המקומי שהשרת מדפיס. לכל ריצה ארוכה מתחילים עם שרת מבודד חדש. 401 עבור קישור שפג תוקפו ו־409 עבור קוטר שאינו במחירון הם תרחישים שליליים מכוונים. בצילומים ובבדיקות נעשה שימוש בנתוני הזרע ובפעולות שבוצעו דרך הפורטל. מכשיר פיזי, מסירת SMS או WhatsApp אמיתית, חתימת נהג והפקת מסמכים חשבונאיים אמיתיים לא נבדקו.
