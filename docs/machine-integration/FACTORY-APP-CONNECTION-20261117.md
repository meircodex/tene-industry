# חיבור התחנה למסכי IronBend הקיימים

בעלים: Production מתזמר סריקה וסטטוס; Machine Integration מחזיק שיקוף ומשוב בלבד. תחום: המסכים הקיימים production-queue, machine, worker-portal והלקוח המשותף worker-machine-feedback. החלטה D0: אין שינוי סכימה, כתיבה לבקר, שינוי שיוך כרטיסים או שינוי מסלול הייצור.

הפער: תחנת 6 מחוברת לשרת, אך מסכי המפעל לא הציגו זאת; פורטל העובד האישי לא הפעיל את המשוב שכבר קיים בסורק הוותיק. משלבים את הרכיב הקיים והמראה שאושר בעבר; אין מסך התחברות לעובד ואין סורק חלופי.

ארכיטקטורה: תצוגת תחנות קוראת את presence ואת השיקוף הקיים. נוכחות תחנה אינה הוכחה לתקשורת PLC. ערכי בקר מסומנים עדכניים רק בחלון חמש שניות, עם נוכחות תחנה פעילה והתאמה לבקר ולכרטיס. חיווי מכונה ישן אינו נדרס. פורטל אישי משתמש במעטפת האימות וההתקן הקיימת, בגישה מוגבלת להרשאות start/complete, ובאותו אימות כרטיס של Production.

בהשלמה: אישור DONE הקיים כולל בחירה לשמור פרמטרים כאשר יש הצעה תקפה. השמירה למוניטור רק לאחר קבלת קבלה עסקית אמיתית. כשל ניטור אינו חוסם סריקה או השלמת כרטיס. תור משוב מופרד לפי משתמש; יציאה/החלפת משתמש מבטלת הקשר ותצוגה. כל קריאה מוגבלת בזמן. אין שיוך אוטומטי של עבודות למכונה.

בדיקה: API הרשאות, זהות תחנה וכרטיס, הזדקנות נתונים, אפס כתיבות עסקיות, סריקה והשלמה עם ובלי מוניטור ובניסיון חוזר; בדיקת דפדפן במסכים הקיימים ובדיקה מלאה npm test. אימות בפריסה אמיתית הוא קריאה בלבד ללא פתיחת כרטיס ייצור או שינוי סטטוס.
