## Shared worker directory and identity projection — 16.11.2026

- Reporting now reads its selectable people from production worker profiles, explicitly linked portal accounts, internal named users, legacy station workers and named approved/revoked unlinked worker devices. Configured people remain selectable without activity in the period, including inactive records labelled accordingly. Shared kiosk identities are not presented as people unless an actual historical receipt refers to one. Names and stable keys only; no credentials/phone numbers. Namespaces prevent coincident numeric IDs or equal names from silently merging people. Existing account/invitation links provide explicit aliases; no matching by name/phone or item assignment.
- ProductionReportWorkers is the common read service for the unified table and its filters/graph/export dataset. It reads actual status/update receipts plus legacy station start/complete/close_prev/end_of_day scans, in bounded item-ID batches. Opening/viewing and unchanged no-op receipts are excluded. Recorded unknown activity and rows without a known reporter can be selected as anonymous. Anonymous receipt snapshots stay anonymous after later enrollment, and existing actor names remain historical snapshots. Readers never backfill or rewrite history. Legacy scan names use their explicit worker ID lookup because that source has no name snapshot.
