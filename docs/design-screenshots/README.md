# צילומי שפת העיצוב

הצילומים נלקחו מקומית עם אותם נתוני דמו מ־`scripts/local-design-demo.js`. הקובץ אינו נטען על ידי השרת ואינו כותב לבסיס נתונים. `before/` הוא המראה של main. `after/` הוא הענף אחרי סבב העיצוב השני.

`before/` הוא המצב שב־main. `after/` הוא הענף הזה.

כל מסך צולם ב־1440px וב־390px.

| --- | --- |
| כניסה | `login-1440.png`, `login-390.png` |
| דשבורד | `dashboard-1440.png`, `dashboard-390.png` |
| הזמנות | `orders-1440.png`, `orders-390.png` |
| הזמנה חדשה | `new-order-1440.png`, `new-order-390.png` |

בעורך הצורה נבדק שמסלול הפתיחה חי: לחיצה על ״בחר צורה״ פותחת את העורך, והזנת 80 בס״מ נשמרת כ־800 מ״מ ומציירת מוט עם התווית ״80 ס״מ״.
