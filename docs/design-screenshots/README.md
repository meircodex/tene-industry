# צילומי שפת העיצוב

הצילומים נלקחו מקומית, בלי בסיס נתונים של מפעל. לכן רשימות ריקות וזה צפוי. ההשוואה היא של השפה החזותית, לא של נתוני ייצור.

`before/` הוא המצב שב־main. `after/` הוא הענף הזה.

כל מסך צולם ב־1440px וב־390px.

| מסך | קבצים |
| --- | --- |
| כניסה | `login-1440.png`, `login-390.png` |
| דשבורד | `dashboard-1440.png`, `dashboard-390.png` |
| הזמנות | `orders-1440.png`, `orders-390.png` |
| הזמנה חדשה | `new-order-1440.png`, `new-order-390.png` |
| עורך צורה אחרי הזנת 80 ס״מ | `after/shape-editor-1440.png`, `after/shape-editor-390.png` |
| לקוחות, קליטה, תור ייצור, מלאי, רכש, מחסן, מכונות, איכות, דוחות, כספים, מחירון, ניהול, פרויקטים, תחזוקה, תמיכה, תקלות, פורטל עובד, פורטל, סריקה, קיוסק | אותו שם קובץ |

בעורך הצורה נבדק שמסלול הפתיחה חי: לחיצה על ״בחר צורה״ פותחת את העורך, והזנת 80 בס״מ נשמרת כ־800 מ״מ ומציירת מוט עם התווית ״80 ס״מ״.
